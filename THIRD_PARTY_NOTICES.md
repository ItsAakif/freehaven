## Fonts and icons

- **No font files are bundled.** The interface uses platform system fonts (Georgia/serif and the system sans face).
- `@expo/vector-icons` ships icon fonts with its package, including Ionicons (MIT) and Font Awesome Free
  (icons CC BY 4.0, fonts SIL OFL 1.1, code MIT). They are redistributed under those licences via the dependency.
- The Freehaven brand mark, adaptive icons, favicon and splash image were generated for this project by
  `scripts/make-icons.py` and are MIT licensed with the rest of the repository.

## Documents and media

- **No books, audiobooks or third-party text are redistributed.** Public-domain texts are downloaded from Project
  Gutenberg at the user's request and stored locally.
- `docs/ocr-fixtures/*.png` and `docs/ocr-fixtures/ground-truth.json` are synthetic pages generated by
  `scripts/make-icons.py`'s sibling script `scripts/make-ocr-fixtures.py`, written for this project. They contain no
  third-party text.
- `docs/ocr-results.json` contains OCR output from those synthetic fixtures.

## Catalogue metadata

Catalogue results are fetched at runtime from Project Gutenberg/Gutendex. Its terms
and attribution requirements apply to that data; Freehaven does not redistribute it.
